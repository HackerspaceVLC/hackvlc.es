Si alguna vez has tocado un proyecto con más gente y habéis acabado mandándoos ficheros, copiando carpetas o sobrescribiendo el trabajo del otro, este taller es para ti. Git resuelve justo eso, y la pieza clave son las **ramas**: te dejan desarrollar algo nuevo sin romper lo que ya funciona y juntarlo después con el trabajo de los demás.

Es un taller práctico: todo lo hacemos con ejercicios en tu portátil, paso a paso, siguiendo el camino de una rama desde que la creas hasta que la subes.

## Para quién

Para principiantes. No hace falta experiencia previa con Git. Si ya lo usas para guardar cambios pero las ramas, los merges y el remoto te dan respeto, también te vendrá bien.

## Qué vamos a ver

1. **Qué es una rama y para qué sirve.** Desarrollar una funcionalidad sin romper lo que ya funciona, colaborar sin pisarse y separar desarrollo de producción.
2. **Traer ramas del remoto.** Actualizar tu repositorio local con `git fetch` y cambiarte a una rama con `git checkout`.
3. **Crear tu propia rama.** Partir de una existente, hacer cambios y guardarlos con commits.
4. **Juntar cambios.** Fusionar ramas con `git merge` y ver cómo funciona una merge request hasta que se aprueba.
5. **Subir tu rama.** Publicarla en el remoto con `git push --set-upstream`.

## Qué necesitas

- Tu portátil con Git instalado.
- Saber moverte un poco por la terminal ayuda, pero no es imprescindible.
