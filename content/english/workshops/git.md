If you have ever worked on a project with other people and ended up emailing files around, copying folders or overwriting each other's work, this workshop is for you. Git solves exactly that, and the key piece is **branches**: they let you build something new without breaking what already works, and bring it together with everyone else's work afterwards.

It is a hands-on workshop: we do everything as exercises on your laptop, step by step, following a branch from the moment you create it until you push it.

## Who it is for

Beginners. No previous Git experience needed. If you already use it to save changes but branches, merges and the remote still make you nervous, it will help you too.

## What we will cover

1. **What a branch is and what it's for.** Building a feature without breaking what already works, collaborating without clashing, and keeping development separate from production.
2. **Getting branches from the remote.** Updating your local repository with `git fetch` and switching to a branch with `git checkout`.
3. **Creating your own branch.** Starting from an existing one, making changes and saving them with commits.
4. **Bringing changes together.** Merging branches with `git merge` and seeing how a merge request works until it gets approved.
5. **Pushing your branch.** Publishing it to the remote with `git push --set-upstream`.

## What you need

- Your laptop with Git installed.
- Getting around a terminal helps, but it is not essential.
