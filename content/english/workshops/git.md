A hands-on Git workshop focused on branches, which is exactly what you need to get right to work on a project with other people without stepping on each other's toes.

What we will do, all as exercises on your laptop:

- **What a branch is and what it's for:** building a feature without breaking what already works, collaborating without clashing, and keeping development separate from production.
- **Getting branches from the remote:** updating your local repository with `git fetch` and switching to a branch with `git checkout`.
- **Creating your own branch:** starting from an existing one, making changes and saving them with commits.
- **Bringing changes together:** merging branches with `git merge` and seeing how a merge request works until it gets approved.
- **Pushing your branch:** publishing it to the remote with `git push --set-upstream`.

**What you need:**
- A laptop with Git installed.
- Getting around a terminal helps, but it is not essential.
